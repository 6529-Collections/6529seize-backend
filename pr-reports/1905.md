# PR Report: Add contextual push notification titles

PR: https://github.com/6529-Collections/6529seize-backend/pull/1905
Branch: `agent-prxt/contextual-push-titles` -> `main`
Related PRs: None

## Summary

Makes wave-scoped push notification titles identify both the action and its
context while remaining concise. Titles now distinguish regular waves, 1:1
DMs, and group DMs.

## What Changed

- Messages, replies, mentions, quotes, reactions, and invitations use a
  consistent actor, action, and context title format.
- Regular waves show the recipient-specific wave display name.
- 1:1 conversations use `DM`; group conversations identify another
  participant and abbreviate larger groups with a remaining-participant count.
- Group-DM classification uses the stable membership count rather than
  nullable participant handles.
- Vote, poll-vote, boost, rating, and priority-alert titles also include their
  wave or DM context.
- Recipient-specific wave display data is cached within each notification batch
  so repeated events for the same wave and recipient reuse the same reads.
- Push bodies, deep links, delivery preferences, and notification creation
  behavior are unchanged.
