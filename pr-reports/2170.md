# PR Report: Retire Prenode registration and preserve Oracle TDH

PR: [#2170](https://github.com/6529-Collections/6529seize-backend/pull/2170)
Branch: `agent-prxt/retire-prenode-registration` → `main`
Related PR: [Frontend #4290](https://github.com/6529-Collections/6529seize-frontend/pull/4290)

## Summary

Retire the obsolete Prenode registry while preserving the current Oracle TDH API. Legacy registration and directory requests return a terminal, uncached 410 with a 6529 Desktop replacement notice.

## What Changed

- Retired: `POST /oracle/register-prenode` and `GET /oracle/prenodes`.
- Removed only the registry validation/listing helpers and their exclusive imports.
- Retained the historical Prenode entity/table and records; no data or schema cleanup.
- `/oracle/docs` remains available as “6529 Oracle TDH API”. Registry operations were already absent from OpenAPI and generated clients, so the shared contract and generated shapes are unchanged.
- No About registration/management endpoints were found in the current route inventory.

Preserved GET endpoints, with existing parameters, validation, responses and TDH behavior:

- `/oracle/tdh/total`
- `/oracle/tdh/above/{value}`
- `/oracle/tdh/above/{value}/entries`
- `/oracle/tdh/percentile/{value}`
- `/oracle/tdh/cutoff/{value}`
- `/oracle/address/{address}`
- `/oracle/address/{address}/breakdown`
- `/oracle/address/{address}/memes_seasons`
- `/oracle/address/{address}/memes_seasons/{season}`
- `/oracle/address/{address}/{contract}/{id}`
- `/oracle/nfts`
- `/oracle/nfts/{contract}`
- `/oracle/nfts/{contract}/{id}`
- `/oracle/nfts/memes_seasons`
- `/oracle/nfts/memes_seasons/{season}`

## Backend Impact

Only the existing `api` service changes. No new services, indexer changes, migrations, queues, credentials or environment settings.

## Backend Deployment

Planned: `api` only; not deployed by request. The frontend no longer consumes the registry. Publish its notice before or alongside the API retirement to avoid a temporary legacy status view.

## Release Notes

Prenodes registration and status-directory APIs return 410 Gone. TDH calculation/read/aggregation routes and their public Oracle documentation remain available.

## Risks / Follow-Ups

Legacy registry clients must stop registering or querying Prenodes and use 6529 Desktop for TDH calculation. Reverting this PR restores the registry capability without recovering data.
