# PR Report: Fix partial TDH cluster reconsolidation

PR: https://github.com/6529-Collections/6529seize-backend/pull/1862
Branch: `agent-prxt/fix-delegations-loop-cluster` -> `main`
Related PRs: None

## Summary

Fixes partial TDH reconsolidation when a wallet returns from a temporary
consolidation to a different confirmed cluster. The affected set now includes
the event wallets, their old derived memberships, and every member of their
current confirmed clusters.

## What Changed

- Uses the pre-update consolidated TDH snapshot to recover old memberships,
  then refreshes it immediately before rebuilding to determine the exact
  derived rows being replaced.
- Resolves current confirmed clusters through bounded, parameterized batches.
- Deletes the exact affected consolidation keys from consolidated TDH,
  consolidated TDH memes, consolidated TDH editions, historic consolidated
  TDH, historic consolidated TDH memes, and NFT TDH before rebuilding the
  complete replacement set.
- Rejects a proposed final state that assigns one wallet to multiple
  consolidation rows, including rows whose wallet list is JSON encoded at
  runtime.
- Covers the A-B to A-C/B and back to A-B regression, including event
  direction, casing, multi-event batches, combined TDH, and stale standalone
  membership.
