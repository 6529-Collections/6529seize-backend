# PR Report: Replace Etherscan randomizer lookup with Sourcify

PR: [Backend PR #2135](https://github.com/6529-Collections/6529seize-backend/pull/2135)
Branch: `agent-prxt/sourcify-randomizer-names` -> `main`

## Summary

NextGen randomizer history now resolves optional contract names through the public Sourcify V2 API instead of Etherscan's retired V1 endpoint.

## What Changed

- Replace `src/etherscan.ts` with `src/sourcify.ts`, requesting only `compilation.name` on the configured NextGen chain.
- Preserve named history entries and use the contract address when no verified name is available. HTTP errors, malformed responses, network failures, and five-second timeouts cannot stop indexing.
- Existing stored history is unchanged. Sourcify verification coverage may differ from Etherscan.

## Backend Impact

Only `nextgenContractLoop` consumes the changed integration. No new services, API contract changes, database/entity/migration changes, or queue changes. Frontend and desktop changes are not required.

## Config / Env

Remove `ETHERSCAN_API_KEY` from `.env.sample`; no backend code consumes it after this change. Existing deployment secrets can be removed. Sourcify requires no replacement key or configuration.

## Backend Deployment

Planned, not deployed by request: redeploy `nextgenContractLoop`. No prerequisite services.
