# PR Report: Meme collaborator invitations

PR: https://github.com/6529-Collections/6529seize-backend/pull/2162
Branch: `agent-prxt/meme-collaborator-invitations` → `main`
Related PR: https://github.com/6529-Collections/6529seize-frontend/pull/4243

## Summary

Artwork submitters can invite multiple collaborating profiles. Each invitee accepts or declines directly; acceptance is final. Voting continues while invitations are pending. Public attribution and collaborator profile submissions/wins include accepted collaborators only.

## What Changed

- Store artwork/terms snapshots and independent invitation statuses. Pending identities are private to the submitter and their own invitee; proxy consent is forbidden.
- Use a shared transaction lock for acceptance and legacy/designated native Main Stage mint selection. Selection freezes the accepted roster and closes unanswered invitations.
- Build artist/profile/Collab mint traits from the saved roster. Preserve accepted artwork and credits in claim editing and Arweave publication; retain artist handles if a profile becomes unavailable.
- Add invitation/acceptance notifications through existing notification and push pipelines. Ownership, voting budgets, submission allowances and configured airdrops retain their existing behavior.
- Preserve the original artist name when edits round-trip the API’s combined credits, and keep that original-name field redacted for moderated artwork.
- Existing submissions/claims without managed records stay compatible. New submissions, including resubmissions, obtain fresh invitations.

## Backend Impact

Two synchronized entities (`meme_collaborations`, `meme_collaboration_invitations`) and generated collaboration state/response endpoints are added. Drop V1/V2 attribution and Main Stage profile queries expose accepted collaborators. No new Lambda, queue, event transport, on-chain contract, environment variable or configuration is introduced. Architecture documentation is updated; the companion frontend updates the help corpus and generated contract.

## Release Notes

Acceptance is final and locks the artwork, title, description and submitter artist name. Unrelated trait corrections remain possible. Pending collaborators never delay minting and cannot join the mint after selection. Collaborator credit grants neither editing rights nor payment splits.

## Risks / Follow-Ups

Retain consent records and snapshot-aware workers while managed claims remain in flight if reverting the feature. Never drop the new tables as part of rollback.
