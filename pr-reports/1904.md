# PR Report: Fix Group DM Notifications

Related PRs: None

## Summary

Fixes notification-feed and push delivery for direct-message groups whose generated visibility-group IDs exceed 50 characters, which commonly occurs once a DM contains three or more participants.

## What Changed

- Widens `identity_notifications.visibility_group_id` from 50 to 100 characters, matching the wave visibility-group field.
- Repairs existing notification rows whose visibility-group IDs were truncated to 50 characters by restoring the authoritative ID from their related wave.
- Adds focused three-person DM coverage for long group IDs, notification precedence, mute behavior, private feed visibility, and push authorization.

## Backend Impact

- New services: None

- API: No contract change; group DM notifications become visible to eligible recipients
- DB/entities/migrations: Widens and backfills `identity_notifications.visibility_group_id`
- Queues/events/integrations: No queue contract change; the existing push pipeline now receives notification IDs that were previously lost after truncated inserts
