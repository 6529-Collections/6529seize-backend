# PR Report: Use global developer mentions for backend alerts

PR: https://github.com/6529-Collections/6529seize-backend/pull/1899
Branch: `agent-prxt/manual-devs-tagging` -> `main`
Related PRs: None

## Summary

Replaces notification-specific developer handle lists with the global
`@devs6529` mention on CI failure, subscription warning/error, and help-bot
escalation paths. Developer audience membership now comes from the existing
`DEVS_6529_MENTION_PROFILE_IDS` configuration.

## What Changed

- CI failures now append `@devs6529` while preserving the exact release
  initiator and contributor attribution backed by `GITHUB_TO_6529_HANDLES`.
- Subscription duplicate-top-up and redemption issue posts now append the
  global developer token, while successful top-up posts keep their dynamic
  top-up-profile mention behavior.
- In-scope help-bot no-reliable-source and uncertain-answer responses now
  append the global developer token. Out-of-scope and technical-failure
  responses remain untagged.
- Obsolete manual-handle parsing, help-bot profile resolution, configuration
  samples, and documentation were removed or updated.
- `DISCORD_DEVS_ROLE` and person-specific artist, winner, contributor, and
  other dynamic mentions are unchanged.

## Backend Impact

- Changed services: `api`, `helpBotReplyLoop`, `subscriptionsTopUpLoop`,

## Config / Env

Keep `DEVS_6529_MENTION_PROFILE_IDS`. It remains the source of truth for the
profiles reached by `@devs6529`.

## Post-deployment environment cleanup
