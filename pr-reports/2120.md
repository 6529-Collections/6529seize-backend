# PR Report: Coinbase ETH price recovery

PR: [#2120](https://github.com/6529-Collections/6529seize-backend/pull/2120)
Branch: `agent-prxt/coinbase-eth-price-recovery` → `main`

## Summary

Replace the failing Mobula ETH/USD source with public Coinbase Exchange live
prices and five-minute historical candles. Detect missing intervals on every
scheduled invocation, resume bounded historical work, and correct affected
transaction and Memes mint USD values in the same database transaction.

## What Changed

- Live collection retains the five-minute schedule and needs no provider key.
- Interior and trailing gaps remain discoverable even after new live prices are
  saved. Ordinary recovery preserves existing samples. Partial/empty Coinbase
  ranges save only real candles; absent closes use expiring daily retry cooldowns
  in Redis so unavailable intervals cannot pin the recovery scan.
- Historical corrections update transaction ETH/USD, value USD, and gas USD, plus
  existing Memes mint proceeds and artist split USD. ETH amounts, counts, and
  payment details are preserved.
- Transaction persistence and mint initialization coordinate with recovery to
  prevent stale concurrent writes. Persistence reads existing database prices
  only, preserves incoming USD when none exists, and normalizes DATETIME precision.
  Atomic repairs have bounded lock waits and a 90-second transaction budget.
- `ETH_PRICE_RESET=true` requests historical upserts without deleting rows. Its
  cursor uses existing Redis, scoped by environment/database, and continues
  across invocations after the flag is cleared. A completed reset must observe false before a new true request.
- No database schema, entity, migration, API contract, or frontend changes.
  `ETHERSCAN_API_KEY` retains its unrelated NextGen use.

## Deployment

Planned, not deployed by request. Before activating recovery, record that the
writer services are running the selected revision and their old invocations have
drained; stop if either is unverified. Keep collector reserved concurrency at one.
Deploy in this order:

1. `transactionsLoop`: `memesTransactionsLoop`, `gradientsTransactionsLoop`,
   `memeLabTransactionsLoop`.
2. `nextgenContractLoop`.
3. `nftsLoop`.
4. `ethPriceLoop`.

No API or `dbMigrationsLoop` deployment is needed. See
[ETH price recovery](../docs/eth-price-recovery.md) for operational details.

## Risks / Follow-Ups

Coinbase candle closes reflect one exchange and do not recreate missed exact
Mobula quotes. Candle closes are applied only at their interval end; existing
off-grid samples remain in place. Missing provider candles remain actual database
gaps, with daily retry cooldowns rather than invented values. Reset scan completion
does not assert complete historical coverage. Cold starts during Redis outages can
retry those intervals sooner. Large resets span many runs; after loss of the Redis cursor,
reassert reset to restart the repeatable upserts. Normal gap recovery does not
require that cursor. Database lock conflicts can defer affected loops until a
retry. Rolling back code does not undo corrected USD data.
