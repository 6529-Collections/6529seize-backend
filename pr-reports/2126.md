# Active TDH vote discovery

[PR #2126](https://github.com/6529-Collections/6529seize-backend/pull/2126) provides the read API for the Active Votes sidebar and discovery page.

`GET /v2/waves/active-votes` returns readable, non-DM TDH, TDH + xTDH and card-set TDH voting waves, including joined and pinned waves. Wave and parent visibility apply before count and pagination. Results use the nearest voting end or next decision, then open-ended votes and stable wave IDs.

Voting windows, unresolved decisions, completed rank strategies and approval winner limits determine activity. The endpoint does not claim personal voting eligibility. It retains legacy voting as the source of truth and leaves search relevance unchanged.

Deploy `api` before the companion frontend. There is no migration, new worker, cache or background refresh service. The runtime query uses existing waves and wave decisions; discovery refresh is initiated by clients.
